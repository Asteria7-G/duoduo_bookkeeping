# Dodo Journal Hand

An offline web-font subset of [LXGW Marker Gothic v1.004](https://github.com/lxgw/LxgwMarkerGothic/releases/tag/v1.004), derived from Tanugo. Copyright notices and the complete SIL Open Font License 1.1 are in OFL.txt.

Subset and family renaming by Dodo Bookkeeping. Original glyph outlines retained. Includes GB2312 Chinese, Latin, punctuation and all application UI characters. Characters outside the subset use the platform fallback font. The WOFF2 font is embedded once in theme/handwriting.wxss; it makes no network requests.
